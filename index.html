    ⚙️ Pengaturan Keamanan & Pengacakan

    📜 Panduan & Kode Google Apps Script (Code.gs)

    1. Buka Google Sheets baru → klik Extensions → Apps Script.
    2. Tempel kode Code.gs di bawah, lalu klik Save (jangan tekan Run).
    3. Klik Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone).
    4. Salin URL Web App (berakhiran /exec) lalu tempel ke kolom URL Webhook di atas atau pada variabel WEBHOOK_URL di Notepad.
